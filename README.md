# MIUI 14 China Android 13 — joyeuse research workspace

> **Safety status: research-only. No flashable ROM is produced by this repository.**

Goal: investigate whether a MIUI 14 China Android 13 port from Xiaomi 12 (cupid) can be adapted for Redmi Note 9 Pro (joyeuse).

## Device and target

- Target device: Redmi Note 9 Pro, codename **joyeuse**
- Source device: Xiaomi 12 China, codename **cupid**
- ROM family: MIUI 14 China (not Global)
- Desired Android base: Android 13
- Candidate source build: **V14.0.10.0.TLCCNXM** (metadata lead; not yet independently validated or downloaded)
- Build environment: GitHub Actions, if feasible
- Non-negotiable constraint: keep the currently working phone untouched

## Current status

This repository is a research workspace. The first milestone is documentation and automated metadata checks only. It does **not** download ROM images, assemble partitions, create a flashable ZIP, or issue any device/fastboot commands.

## Why this is not a ROM build yet

A source ROM for cupid is not directly compatible with joyeuse. Before any build is considered, the project needs verified evidence for:

1. Exact source package version, region, Android version, authenticity, and checksum.
2. Target-specific joyeuse device tree, kernel, vendor blobs, firmware, and partition layout.
3. A documented, device-specific porting method and licensing constraints.
4. A compatibility plan for hardware-specific components (camera, modem, sensors, fingerprint, audio, graphics, and power).
5. A recovery plan independently verified before any device-side experiment.

A successful CI run only means repository checks passed. It does **not** mean a ROM builds, boots, or is safe to install.

## Safe milestones

1. Record source package metadata and checksums without committing proprietary ROM images.
2. Review public joyeuse device-tree and kernel sources; mark their age and limitations.
3. Create a compatibility matrix for the cupid source versus joyeuse target.
4. Add static checks only after each source and method is verified.
5. Keep all device flashing and partition-writing out of CI.

## Do not

- Do not lock the bootloader.
- Do not flash images or recovery packages generated by this repository.
- Do not use scripts that automatically run fastboot, adb, erase, format, or write partitions.
- Do not treat a successful build or archive as proof of device compatibility.

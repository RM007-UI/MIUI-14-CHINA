# MIUI 14 China — joyeuse research workspace

> **Safety status: research-only. No flashable ROM is produced by this repository.**

Goal: investigate whether a genuine **MIUI 14 China based on Android 12** port is technically feasible for the Redmi Note 9 Pro variant `joyeuse`.

## Device and target

- Target device codename: `joyeuse`
- ROM family: MIUI 14 China (not Global)
- Desired Android base: Android 12
- Build environment: GitHub Actions, if feasible
- Non-negotiable constraint: keep the currently working phone untouched

## Current status

This repository was initially empty. The first milestone is intentionally limited to documentation and automated metadata checks. It does **not** download ROM images, assemble partitions, create a flashable ZIP, or issue any device/fastboot commands.

## Why this is not a ROM build yet

A device codename match alone is not enough. Before any ROM build is considered, the project needs verified evidence for:

1. An exact MIUI 14 China Android 12 source package and its authenticity.
2. The source device and target device partition/layout compatibility.
3. A documented, device-specific porting method and licensing constraints.
4. Required proprietary components and a lawful, reproducible way to obtain them.
5. A reliable recovery plan independently verified before any device-side experiment.

A successful CI run only means these repository checks passed. It does **not** mean a ROM boots or is safe to install.

## Safe milestones

1. Record verified source/package metadata without committing proprietary ROM images.
2. Review public device-tree and kernel sources for the exact `joyeuse` variant.
3. Add further static checks only after the source and method are verified.
4. Keep all device flashing and partition-writing out of CI.

## Do not

- Do not lock the bootloader.
- Do not flash images or recovery packages generated by this repository.
- Do not use scripts that automatically run `fastboot`, `adb`, erase, format, or write partitions.
- Do not treat a successful build or archive as proof of device compatibility.

## Contributions

Please include source URLs, exact version identifiers, hashes where available, and evidence that the information applies to `joyeuse`. Do not upload proprietary firmware images or personal device backups.
